# Emerald Rupture Locke

Nuzlocke tracker for Emerald Rupture 2.6.2. One page, no build step: open `index.html` (or `/nuzlocke/` on GitHub Pages).

- Every area, gift, trade and fossil in story order, with encounter odds and the dupes clause.
- Every boss team on Normal and Hard (plus the Doubles teams), level caps, team comparison, box, graveyard, Pokédex.
- **Read .sav**: loads your party and all 14 boxes (reader and id tables from `js/savereader_rupture.js`), matches them to tracked encounters, flags fainted and missing Pokémon and Pokémon over the level cap.
- Runs save in the browser. Optional private-gist sync (Run tab) keeps them across devices. "Download backup" writes a file.
- Installable: use "Add to Home Screen" on a phone.

Generated from `EmeraldRupture-2.6.2_Documentation.xlsx`.
